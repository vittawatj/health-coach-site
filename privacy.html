Privacy policy

Last updated 28 October 2026

Health Coach is a personal tool used only by its owner. This policy describes how it handles Google user data.

Data accessed

  • Google Health API (read-only): activity and fitness, health metrics and measurements, and sleep data.
  • Gmail API (send only): permission to send email. Health Coach does not read, list or delete any email.

How the data is used

Once a week the owner's own data is used to calculate summary scores and to write a coaching report, which is emailed to the owner. To write the coaching notes, the weekly summary is sent to Anthropic's Claude API. Data is used for nothing else.

Storage and sharing

Health Coach does not keep a database. Data is processed during the weekly run and discarded afterwards, except for the report email itself. Data is not sold, not used for advertising, and not shared with anyone other than the processing step described above.

Limited Use

Health Coach's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Use the support email shown on the Google sign-in screen for this app.
